## 0.25.0 - 2026-09-03

- **Builders are `Clone`** ([#198](https://github.com/arthur-debert/clapfig/issues/198), [#199](https://github.com/arthur-debert/clapfig/pull/199)) — `Builder` and `TypedBuilder<C>` implement `Clone`, so a host that configures one builder can build a fresh resolver per invocation, with per-invocation overrides applied to the clone. Hooks are shared by the clone and fire on both.
- **Typed `ConfigResult` values** ([#199](https://github.com/arthur-debert/clapfig/pull/199)) — `ConfigResult::Listing.entries` is `Vec<(String, Value)>` and `ConfigResult::KeyValue.value` is a `Value`, so a host rendering `config list` or `config get` structurally keeps integers, booleans and arrays typed. `rendered` is unchanged. This is a breaking change for callers that matched on the string forms.
- **`cli_override_str`** ([#199](https://github.com/arthur-debert/clapfig/pull/199)) — `Builder::cli_override_str(key, raw)` and its typed twin parse a raw string with the same scalar rule the environment layer uses (bool, then integer, then float, then string) and place it on the override layer. Made for a host's `--set key=value` style flag.
- Install snippets now reference 0.25.
