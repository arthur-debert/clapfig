## 0.25.1 - 2026-09-03

- **`arbitrary_precision` dropped from the serde_json dependency** ([#202](https://github.com/arthur-debert/clapfig/issues/202), [#203](https://github.com/arthur-debert/clapfig/pull/203)) — Cargo unifies features across a dependency graph, so every host that depended on clapfig got the feature too, and a `serde_json::Number` then serialized as a `{"$serde_json::private::Number": "..."}` map through any serializer other than serde_json's own. The JSON adapter keeps its guarantees without it: out-of-range integer and float literals stay typed parse errors (the adapter lexes numbers itself), and an edit keeps untouched keys byte-identical through an owned document tree and one pretty-printer shared with `serialize`. No public API change.
