**TOML file spans** ([#148](https://github.com/arthur-debert/clapfig/issues/148), epic [#146](https://github.com/arthur-debert/clapfig/issues/146)) — `TomlAdapter::parse` walks one `toml_edit` document and returns the value tree together with a complete path → `{ key, value }` span index (ADR-0005, ADR-0006). Unknown-key errors consult that index (key span for the caret; line/column derived at render time). `find_key_line` is gone. YAML and JSON fill their own indexes (WS03/WS04); missing lookup still omits the line rather than inventing a heuristic. `normalize_keys(true)` rewrites span-index paths with the value tree so the snippet still shows the spelling the user wrote.
