**Provenance YAML spans** ([#149](https://github.com/arthur-debert/clapfig/issues/149), epic [#146](https://github.com/arthur-debert/clapfig/issues/146)) — `YamlAdapter::parse` still builds `Value` with `serde_norway` (ADR-0003) and now fills `Parsed.spans` in the same call via `yamlpath` (ADR-0008). Every path in the returned tree gets a `{ key, value }` entry (ADR-0006); written array elements have `key: None`. A path that exists only because an alias expanded carets the `*name` token for both sides — including sequence items that exist only via expansion — not the anchor's nested keys.

Unknown-key rendering consults that index (key span for the caret; line/column derived at render time). `find_key_line` is gone. The document root is an index entry (`key: None`, exact value span), so a YAML scalar or sequence at the root locates `InvalidValue` with line and caret.
