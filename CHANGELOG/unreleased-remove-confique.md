**Removed the confique-driven static path: one schema model, hard removal** ([#104](https://github.com/arthur-debert/clapfig/issues/104)) — `#[derive(clapfig::Schema)]` + `Clapfig::typed::<C>()` is now THE typed path; the parallel confique-backed path (`Clapfig::builder::<C>()`, `ClapfigBuilder<C>`, `Resolver<C>`) is gone, along with the `confique` dependency itself. Every feature that carried a "static-path asterisk" now behaves uniformly: JSON Schema emits `type` on every leaf and `enum` sets; `config gen` runs through the runtime emitter with `# Allowed:` and placeholder hints; post-merge type errors name the offending key; `ArrayOf`/`MapOf` containers and schema-inline strictness work across every consumer of the schema model (templates, JSON Schema, strict validation). The `derive` Cargo feature is now a default feature.

**Migration from `#[derive(confique::Config)]`:**

- On the struct: `#[derive(confique::Config, ...)]` → `#[derive(clapfig::Schema, serde::Serialize, serde::Deserialize, ...)]`. The derive does not generate a serde `Deserialize` impl — derive it yourself.
- Attributes: `#[config(default = ..., env = ...)]` → `#[clapfig(default = ..., env = ...)]`. Drop `#[config(nested)]` — a field whose type also derives `Schema` nests automatically. `#[config(deserialize_with = f)]` → serde's `#[serde(deserialize_with = "f")]` (note: unlike confique, schema defaults also pass through the deserializer, so write defaults in pre-normalized form or accept the normalization).
- Builder: `Clapfig::builder::<C>()` → `Clapfig::typed::<C>()`. Same surface (`app_name`, `search_paths`, `env_prefix`, `strict*`, `cli_override*`, `post_validate`, `load`, `load_with_unknowns`, `handle*`, `build_resolver`). (#105 shipped this as `Clapfig::schema_builder::<C>()`; DER01-WS01 renamed it — see `unreleased-derive-polish-structural-collapse.md`.)
- Errors: `ClapfigError::ConfigError(confique::Error)` is removed. Missing required fields now surface as `ClapfigError::MissingRequired { key }` and type mismatches as `ClapfigError::InvalidValue { key, .. }` with the exact offending key.
- Tree-walk resolver: the typed `Resolver<C>` removed at confique-removal is restored as `TypedResolver<C>` from `TypedBuilder::build_resolver()` (DER01-WS06 — see `unreleased-derive-polish-cli-typed-resolver.md`). The Map-out handle is `Resolver`; `resolve_at` returns `clapfig::value::Map`, not `toml::Table` (pipeline swap — see `unreleased-value-model-pipeline-swap.md`). Also renamed at confique-removal and later: `meta::doc_for::<C>` → `meta::doc_for(C::schema(), key)` (#105's `doc_for_runtime` was renamed in DER01-WS01); `schema::generate_schema::<C>()` → `json_schema::generate_schema(C::schema())`; typed `ops::generate_template` / `get_value` / `list_values` / `get_scope_value` and `persist::set_in_document::<C>` / `persist_value::<C>` (runtime twins remain).
- Field naming: `#[serde(rename = "...")]` on a field is honored by the schema (the schema follows serde's spelling, so no paired attribute is needed); a `#[clapfig(rename)]`/`#[serde(rename)]` pair must match — a differing pair is a derive-time error. Struct-level `#[serde(rename_all = "...")]` is honored: the schema converts field names with serde-exact semantics ([#107](https://github.com/arthur-debert/clapfig/issues/107), DER01-WS04), so config keys and the typed deserialize agree on the converted spellings. `#[clapfig(rename_all = "...")]` converts the schema only (for typed loading pair it with the serde spelling naming the same rule — a differing pair is a derive-time error). A serialize-only `#[serde(rename_all(serialize = "..."))]` is allowed — it doesn't affect config loading. (`rename_all` on unit-only *enums* is fully supported.)
- `Vec<NestedStruct>` fields: emit `Field::ArrayOf` (DER01-WS03, [#106](https://github.com/arthur-debert/clapfig/issues/106) — see `unreleased-derive-arrays.md`). `Vec<UnitEnum>` flattens to a `LeafType::Array(Enum)` leaf. Remaining unsupported constructs (`Vec<Vec<...>>`, `Vec<Option<T>>`, `Vec<clapfig::value::Value>`, maps of arrays of schema types) keep derive-time errors naming the `#[clapfig(value)]` escape hatch.
- Confique features with no clapfig equivalent (`#[config(partial_attr(...))]`, `#[config(validate = ...)]`): use serde attributes on the struct and `post_validate` respectively.
