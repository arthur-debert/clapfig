**Removed the confique-driven static path: one schema model, hard removal** ([#104](https://github.com/arthur-debert/clapfig/issues/104)) — `#[derive(clapfig::Schema)]` + `Clapfig::schema_builder::<C>()` is now THE typed path; the parallel confique-backed path (`Clapfig::builder::<C>()`, `ClapfigBuilder<C>`, `Resolver<C>`) is gone, along with the `confique` dependency itself. Every feature that carried a "static-path asterisk" now behaves uniformly: JSON Schema emits `type` on every leaf and `enum` sets; `config gen` runs through the runtime emitter with `# Allowed:` and placeholder hints; post-merge type errors name the offending key; `ArrayOf`/`MapOf` containers and schema-inline strictness work everywhere. The `derive` Cargo feature is now a default feature.

**Migration from `#[derive(confique::Config)]`:**

- On the struct: `#[derive(confique::Config, ...)]` → `#[derive(clapfig::Schema, serde::Serialize, serde::Deserialize, ...)]`. The derive does not generate a serde `Deserialize` impl — derive it yourself.
- Attributes: `#[config(default = ..., env = ...)]` → `#[clapfig(default = ..., env = ...)]`. Drop `#[config(nested)]` — a field whose type also derives `Schema` nests automatically. `#[config(deserialize_with = f)]` → serde's `#[serde(deserialize_with = "f")]` (note: unlike confique, schema defaults also pass through the deserializer, so write defaults in pre-normalized form or accept the normalization).
- Builder: `Clapfig::builder::<C>()` → `Clapfig::schema_builder::<C>()`. Same surface (`app_name`, `search_paths`, `env_prefix`, `strict*`, `cli_override*`, `post_validate`, `load`, `load_with_unknowns`, `handle*`).
- Errors: `ClapfigError::ConfigError(confique::Error)` is removed. Missing required fields now surface as `ClapfigError::MissingRequired { key }` and type mismatches as `ClapfigError::InvalidValue { key, .. }` with the exact offending key.
- Removed API without a direct replacement: `Resolver<C>` (typed tree-walk resolver) — use `Clapfig::runtime(C::schema_arc().as_ref().clone()).build_resolver()` (or the runtime builder directly) and deserialize the per-leaf `toml::Table`; a typed `SchemaConfigBuilder::build_resolver` is a candidate follow-up. Also removed: `meta::doc_for::<C>` (use `meta::doc_for_runtime(C::schema(), key)`), `schema::generate_schema::<C>()` (use `schema::generate_schema(C::schema())`), `ops::generate_template::<C>` / `get_value` / `list_values` / `get_scope_value`, and `persist::set_in_document::<C>` / `persist_value::<C>` (runtime twins `set_in_document_runtime` / `persist_value_runtime` remain).
- Confique features with no clapfig equivalent (`#[config(partial_attr(...))]`, `#[config(validate = ...)]`): use serde attributes on the struct and `post_validate` respectively.
